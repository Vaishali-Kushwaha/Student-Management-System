Student Management System


Project Overview :-
Student Management System is a desktop-based application developed using Python, Tkinter, and MySQL. It helps users manage student records through a simple graphical user interface.


Features :-

1. Add Student
2. View Students
3. Search Student by ID or Name
4. Update Student Details
5. Delete Student
6. Clear Form
7. Duplicate Email Validation
8. Email, Phone, Age and Semester Validation
9. Delete and Exit Confirmation
10. MySQL Database Integration


Technologies Used :-
    Python
    Tkinter
    MySQL
    MySQL Connector/Python


Student Information :-
The system stores the following details:
    Student ID
    Name
    Email
    Phone
    Age
    Course
    Branch
    Semester

How to Run :-

1. Install Python.
2. Install MySQL.
3. Install MySQL Connector using:
    pip install mysql-connector-python
4. Create the database using the database.sql file.
5. Update the MySQL password in the Python file.
6. Run the application using:
7. python student_management.py
